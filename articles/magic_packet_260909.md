# Wake on LAN (WOL) によるリモート PC 電源投入

## WOL / マジックパケットの仕組み
WOL（Wake On LAN）は、ネットワーク経由で電源投入の指令を送る機能です。
同一サブネット内のブロードキャストアドレス（`FF:FF:FF:FF:FF:FF`）に対して、対象機器（起動したいPC）の NIC の **MAC アドレスを 16回連続して含めた UDP パケット（Magic Packet）** を送信することで、電源が切断された PC を起動させます。

:::message
**補足: セグメント越えのWOLについて**
通常のブロードキャストはルーターを越えられないため、WOLは「同一セグメント内」でのみ有効です。外部ネットワークやVPN越しにWOLを行いたい場合は、ルーター側で「ダイレクトブロードキャスト（Directed Broadcast）」を許可し、特定セグメントへのブロードキャスト転送を設定するなどの工夫が必要になります。
:::

## 前提要件と ACPI ステート
WOL を正常に動作させるためには、対象マシンが **S5 (完全電源オフ)** または **S3 (スリープ)** 状態から NIC パケットを検知できる状態にしておく必要があります。（ACPI 2.0に対応している製品であること）

| ステート | 状態 | WOL対応 |
| :---: | :--- | :---: |
| **S0** | 稼働中 | - |
| **S1** | CPUクロック停止、メモリ保持、ハードディスクの回転停止 | 〇 |
| **S2** | CPUオフ、メモリ保持、ハードディスクのオフ | 〇 |
| **S3** | スリープ / サスペンド (CPUオフ、メモリ保持) | 〇 |
| **S4** | 休止状態 (ハイブリッドシャットダウン / Windowsの高速スタートアップ等) | **× (不可の場合が多い)** |
| **S5** | クラシックシャットダウン (電源オフ) | 〇 (BIOS/NIC設定依存) |

## Windows 側の注意点 (高速スタートアップの無効化)
Windows 10/11 では、シャットダウンからの復帰を早めるためにデフォルトで「高速スタートアップ」が有効になっています。
これが有効な場合、シャットダウン時は **S4 ステート** 相当の移行となり、WOL のマジックパケットを受信できなくなるケースが多いため、無効化が必要です。

1. `コントロールパネル` を開く。
2. `ハードウェアとサウンド` ＞ `電源オプション` ＞ `電源ボタンの動作を選択する` をクリック。
3. `現在利用可能でない設定を変更します` をクリック。
4. シャットダウン設定の **「高速スタートアップを有効にする (推奨)」のチェックを外す**。
5. 「変更の保存」をクリック。

## HP Z440 ワークステーションの BIOS 設定例
BIOS側でもWOLの設定を有効にする必要があります。NIC側に詳細設定がある場合はそちらも併せて設定します。

1. **ブートオプション**: `詳細設定` ＞ `ブートオプション` ＞ `高速起動` を **OFF** にする。
2. **WOL機能設定**: `内蔵デバイスオプション` ＞ `Wake On LAN` ＞ **ハードドライブからのブート** を選択する。
3. **省電力設定**: `電源管理オプション` ＞ `S4/S5最大省電力` の **チェックを外す**。

## nWOL ツールでの運用
PowerShell等のコマンドラインからパケットを送信することも可能ですが、GUIで手軽に管理・操作したい場合は「nWOL」などのフリーソフトが便利です。

- **設定方法**: 接続したい対象PCの「MACアドレス」と「IPアドレス（ホスト名も登録しておくと管理しやすい）」を設定し保存。
- **実行方法**: リストから対象PCを選び、電源ボタンアイコンをクリックするだけでマジックパケットが送信されます。

:::message
**注意点**
電源が入ってPCが起動しても、WOLツール（nWOL等）側のGUI表示は自動で状態が切り替わらない（起動状態を検知する機能がない、または設定されていない）場合があります。起動確認は別途Ping等で行う必要があります。
:::

## マジックパケットの注意点
1. マジックパケットの送出範囲
WOLは基本的に同一ネットワーク内での利用が前提となります。
異なるネットワーク間での利用には、ルーターがブロードキャスト通信を転送できる機能を持っていれば その設定をすることでネットワークをまたいで利用することが可能なケースもあるようです。

2. 無線LANの制限
基本的には有線接続のPCが対象となります。
無線LANに接続されているPCでは、完全にシャットダウンしている状態からの起動はできません。

3. 高速スタートアップの無効化が必要
Windowsの高速スタートアップ機能が有効になっているとマジックパケットを受信するためのNICに電力が供給されなくなるため、WOLを使用することができません。

## ダイレクトブロードキャスト
マジックパケットはブロードキャストを使用するため、基本的にセグメントをまたいで実行することはできません。
ただ、このダイレクトブロードキャストの機能を使用することで、ブロードキャスト通信を指定のポートが受け取ることで、転送先のセグメントにブロードキャストすることが可能になります。

> ダイレクトブロードキャストについては、セキュリティ上の問題があることから、IPネットワークにおける経路制御装置であるルータにおいて、転送されないようにデフォルトで設定されているのが一般的です。
> Cisco製品のルータでも、IOS12.0以降はデフォルトではダイレクトブロードキャストを転送しないように設定されています。
> ただし、リモートネットワークなどから WoL (Wake on LAN) パケットを転送したい場合などは、ダイレクトブロードキャストを転送するようにCiscoルータではI/F上で以下の通り設定します。

```bash
Cisco(config-if)# ip directed-broadcast
```


## おわりに
マジックパケットを使用したWOLは、リモートからのPC起動や省電力運用に非常に便利な機能です。
でも、その分ブロードキャスト通信を使用するためのセキュリティリスクが伴い、DoS 攻撃のリフレクターとして動作しうるという点があります。

前にいた企業でも、マジックパケットはWindowsのデバイスマネージャーから無効にしていたし（Wake On Magic Packet)、
普段使う必要はない機能ではありますが、知識として知っていて損はないと感じました。
