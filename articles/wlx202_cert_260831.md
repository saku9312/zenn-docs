企業ネットワークなどで利用される強固なWi-Fiセキュリティ「WPA2/WPA3-Enterprise (EAP-TLS)」を、Yamaha WLX202とProxmox上のLXCコンテナを使って構築する手順を解説します。

## 構成概要

今回は2つのLXCコンテナを用いて、認証局（CA）とRADIUSサーバーを分離した構成にします。

*   **コンテナ1 (Private CA)**: 証明書の発行・管理を行う（Easy-RSAを利用）
*   **コンテナ2 (RADIUS)**: WLX202からの認証要求を受け、証明書ベースで認証する（FreeRADIUSを利用）
*   **Authenticator**: Yamaha WLX202（アクセスポイント）

:::message
**なぜCAとRADIUSを分けるのか？**
プライベートCAのルート秘密鍵（Root CAの鍵）はセキュリティの要です。これが漏洩すると不正な証明書を偽造できてしまうため、RADIUSサーバーとは切り離し、CAは普段ネットワークから隔離（または停止）しておくのがベストプラクティスです。
:::

## 1. プライベートCAの構築と証明書発行（コンテナ1）

まずはCA用コンテナ（AlmaLinux10）にSSH接続し、証明書管理ツールである `easy-rsa` を導入します。

### 1-1. Easy-RSAのインストールと初期化

パッケージをインストール後、作業用ディレクトリを作成してPKI（公開鍵暗号基盤）を初期化します。

```bash
# epelリポジトリの登録
dnf install epel-release

# パッケージのインストール
dnf update
dnf install easy-rsa

# Easy-rsaバージョンの確認
ls -la /usr/share/easy-rsa/
lrwxrwxrwx 1 root root    5 Dec 15  2025 3 -> 3.2.5
lrwxrwxrwx 1 root root    5 Dec 15  2025 3.0 -> 3.2.5
drwxr-xr-x 3 root root 4096 Sep  1 14:09 3.2.5

# DNFでインストールして出来たファイルを /etc/ 以下へコピー
mkdir -p /etc/openvpn/easy-rsa
cp -r /usr/share/easy-rsa/3/* /etc/openvpn/easy-rsa/

cd /etc/openvpn/easy-rsa/

# PKIの初期化（※既存データがある場合は初期化されるので注意）
./easyrsa init-pki

# 証明書期間の設定
cp ./pki/vars.example ./pki/vars
vi ./pki/vars

## 124行目
# 証明書の有効期限の設定 (日数)
# 例: 7300日 = 20年
set_var EASYRSA_CA_EXPIRE    7300

## 128行目
# 中間証明書の有効期限 (日数)
# 例: 7300日 = 20年
set_var EASYRSA_CERT_EXPIRE  7300

## 135行目
# CRL（証明書失効リスト）の有効期限 (日数)
# 例: 7300日 = 20年
set_var EASYRSA_CRL_DAYS       180

# ルートCAの作成
./easyrsa --vars=pki/vars build-ca
最初にパスフレーズの入力
Common Name にはサーバー名（ドメイン）を入力

# 証明書の所在確認
cd /etc/openvpn/easy-rsa/pki/
ca.crt　があればOK
```

実行すると、Root CAの秘密鍵を保護するパスフレーズと、CAの共通名（Common Name: `MyHome-CA` など）の入力が求められます。完了すると `pki/ca.crt` （ルート証明書）が生成されます。

## 2. FreeRADIUSの構築とEAP-TLS設定（コンテナ2）

RADIUS用コンテナにログインし、FreeRADIUSを構築します。

### 2-1. インストールと証明書の配置

```bash
sudo apt update
sudo apt install freeradius freeradius-utils
```

CAコンテナで作成した以下3つのファイルを、RADIUSコンテナの `/etc/freeradius/3.0/certs/` にSCP等で転送・配置します。

1.  `ca.crt`
2.  `radius-server.crt`
3.  `radius-server.key`

FreeRADIUSはセキュリティ上 `freeradius` ユーザーで動作するため、秘密鍵の読み取り権限を付与します。これを忘れるとサービスが起動しません。

```bash
sudo chown freeradius:freeradius /etc/freeradius/3.0/certs/radius-server.key
sudo chmod 640 /etc/freeradius/3.0/certs/radius-server.key
```

### 2-2. EAP-TLSモジュールの設定

`/etc/freeradius/3.0/mods-available/eap` をテキストエディタで編集し、証明書認証を有効化します。

```text:/etc/freeradius/3.0/mods-available/eap
# デフォルトの認証方式をtlsに変更
default_eap_type = tls

# (中略) tls-config セクションで証明書のパスを指定
tls-config tls-common {
    private_key_file = /etc/freeradius/3.0/certs/radius-server.key
    certificate_file = /etc/freeradius/3.0/certs/radius-server.crt
    ca_file = /etc/freeradius/3.0/certs/ca.crt
    
    # ※ private_key_password が設定されている行があればコメントアウト（#）する
    # private_key_password = whatever
}
```

### 2-3. WLX202のクライアント登録

`/etc/freeradius/3.0/clients.conf` の末尾に、WLX202からのアクセスを許可する設定を追記します。

```text:/etc/freeradius/3.0/clients.conf
client wlx202 {
    ipaddr = 192.168.1.50      # WLX202のIPアドレス
    secret = YourSecretKey123  # WLX202と共有するシークレットキー
    shortname = yamaha_ap
}
```

設定が完了したらサービスを再起動し、ステータスを確認します。

```bash
sudo systemctl restart freeradius
sudo systemctl status freeradius
```

`active (running)` になっていれば、RADIUSサーバーの準備は完了です。

## 3. Yamaha WLX202の設定

WLX202のWeb GUIへログインし、RADIUSサーバーとの連携を設定します。

1. **RADIUSサーバー情報の登録**
   * **RADIUSサーバー（PRIMARY）**: `有効`
   * **IPアドレス**: FreeRADIUSコンテナのIPアドレス
   * **ポート番号**: `1812`
   * **共有暗号キー**: `clients.conf` で設定した `secret` （例: `YourSecretKey123`）

2. **VAP設定（SSIDの設定）**
   * [無線設定] ＞ [VAP設定] で対象のSSIDを選択。
   * **認証方式**: `WPA2-Enterprise` （環境に合わせて `WPA2/WPA3-Enterprise` も可）
   * **暗号化方式**: `AES`

設定を保存し、WLX202本体へ設定を送信して適用します。

## 4. 端末への証明書インストールと接続

最後に対象の端末（Windows, macOS, iOS, Android等）に証明書をインストールします。

1. **ルートCA証明書 (`ca.crt`) のインポート**
   OSの「信頼されたルート証明機関」としてインストールします。
2. **クライアント証明書 (`client01.p12`) のインポート**
   エクスポート時に設定したパスワードを入力し、「個人」または「ユーザー証明書」としてインストールします。
3. **Wi-Fi接続**
   対象のSSIDに接続する際、認証方式に **EAP-TLS** （または「スマートカードやその他の証明書」）を選択し、インポートしたクライアント証明書を指定すれば接続完了です。

:::message alert
**接続に失敗する場合のトラブルシューティング**
FreeRADIUS側で以下のコマンドを実行してデバッグモードで起動し、その状態でWi-Fi接続を試行してください。

```bash
sudo systemctl stop freeradius
sudo freeradius -X
```

コンソールに大量のログが流れます。証明書のパス間違いや権限エラー、Secretキーの不一致などの具体的なエラー原因を特定しやすくなります。
:::
