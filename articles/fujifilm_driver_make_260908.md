富士フイルムビジネスイノベーション（旧富士ゼロックス）のプリンターを、社内ネットワーク上の複数台のPCへ一括で自動配布・設定する手順をまとめました。
「ドライバー配布ツール」を用いたパッケージ化から、旧機種の削除、バッチファイル化、そしてActive DirectoryのGPO（グループポリシー）を使ったサイレント展開までを網羅しています。

※未検証ですが、これでうまくいくはずです。実際の運用前にテスト環境での動作確認を推奨します。


## 1. 事前準備と基本的なパッケージの作成

富士フイルム公式の「ドライバー配布ツール」を使用すると、IPアドレスや機器名、初期設定などを組み込んだ単一の実行ファイル（.exe）を作成できます。

1. **ツールの入手**: 富士フイルムの公式サイトから対象プリンターのドライバーと「ドライバー配布ツール」をダウンロードし、作業用PCで解凍します。
2. **設定の組み込み**: ツールを起動して `.inf` ファイルを読み込ませ、IPアドレス（標準TCP/IPポート）とプリンター名（表示名）を指定します。
3. **パッケージ（EXE）の出力**: 設定内容を含んだ専用の `.exe` 形式のインストーラーとして書き出します。

## 2. 複数プリンターの一括パッケージ化（CSV活用）

複数台のプリンターを一度に追加したい場合、CSVファイルによる一括読み込みが便利です。

- **CSVの準備**: 「プリンター表示名」「IPアドレス」「ポート名」などを記載したリストを用意します。
- **インポートと生成**: ツールの一括作成機能でCSVを読み込ませることで、複数の設定を内包した1つの統合インストーラーを作成可能です。

:::message alert
CSVの文字コード指定や、IPアドレスのフォーマットに誤りがあると文字化けや取り込みエラーの原因になるため注意してください。
:::

## 3. ネットワーク（サブネット）による自動切り替え

PCが属するネットワーク（IPアドレス帯）に応じて、インストールするプリンターを動的に切り替えることも可能です。

1. ツール内で「配布先条件」をIPアドレスに設定。
2. `192.168.10.1`～`192.168.10.254`（本社）、`192.168.20.1`～（支社）などの条件と、対応するプリンターを紐付けます。
3. これらを一つのパッケージに出力することで、PC側で実行した際に自身のIPを判定し、適切なプリンターのみが追加されます。

## 4. 旧ドライバーの削除と新ドライバーのサイレントインストール

完全無人（サイレント）で、既存の古いプリンターを削除してから新しいプリンターを追加するフローを構築します。
コマンドプロンプトからは `/s` スイッチを付けることでインストーラーをサイレント実行できます。

### 自動展開用バッチファイル（完全版）

共有サーバーのネットワークパス（UNCパス）からの直接実行に対応し、旧プリンターの削除、プリントスプーラーの再起動、新ドライバーのインストール、さらに共有サーバーへのログ出力までを行うバッチファイルです。

```bat:install_printer.bat
@echo off
chcp 932 >nul

:: ネットワークパス(UNC)を作業ドライブとして一時割り当て
pushd "%~dp0"

:: 変数定義
set "OLD_PRINTER_NAME=旧プリンター表示名"
set "INSTALLER_NAME=FujifilmSetup.exe"
:: 同時アクセスの競合を防ぐため、ファイル名にPC名を含める
set "LOG_PATH=\\ServerName\Share\Logs\PrinterInstall_%COMPUTERNAME%.log"
set "DATETIME=%DATE% %TIME:~0,8%"

echo 旧プリンターオブジェクトを削除中...
powershell -NoProfile -ExecutionPolicy Bypass -Command "Remove-Printer -Name '%OLD_PRINTER_NAME%' -ErrorAction SilentlyContinue"

echo 印刷スプールを再起動中...
net stop spooler /y >nul 2>&1
net start spooler >nul 2>&1

echo 新ドライバーをインストール中...
if exist "%INSTALLER_NAME%" (
    :: サイレントインストールを実行し、終了まで待機
    start /wait "" "%INSTALLER_NAME%" /s
    
    :: 終了コード（ERRORLEVEL）で成否を判定
    if %ERRORLEVEL% EQU 0 (
        echo [%DATETIME%] [SUCCESS] インストール成功 >> "%LOG_PATH%"
    ) else (
        echo [%DATETIME%] [ERROR] 失敗 (エラーコード: %ERRORLEVEL%) >> "%LOG_PATH%"
    )
) else (
    echo [%DATETIME%] [ERROR] インストーラーが見つかりません >> "%LOG_PATH%"
)

:: 一時割り当てしたドライブを解除
popd
```

:::message
UNCパス上から実行する場合、`pushd "%~dp0"` を使用して一時的なネットワークドライブを割り当てることで、直下のファイルへのアクセスが正常に行われます。
:::

## 5. グループポリシー（GPO）による自動配信手順

作成したバッチファイルをActive DirectoryのGPOを利用して、ドメイン参加PCの起動時に自動適用します。

1. **GPOの作成**: GPMC（グループポリシーの管理）を開き、対象のPCが所属するOUに新しいGPOを作成・リンクします。
2. **スクリプトの配置**:
   `コンピューターの構成` ＞ `ポリシー` ＞ `Windows の設定` ＞ `スクリプト (スタートアップ/シャットダウン)` ＞ `スタートアップ` を開きます。
   「ファイルの表示」をクリックし、開いたSYSVOLフォルダへ上記の `install_printer.bat` と `FujifilmSetup.exe` をコピーします。
3. **スクリプトの指定**:
   スタートアップのプロパティ画面に戻り、「追加」からSYSVOLに配置したバッチファイルを選択します。
4. **アクセス権の確認（SYSVOL以外に配置する場合）**:
   SYSVOL以外の共有ファイルサーバーから実行・ログ出力を行う場合、実行主体は各ユーザーではなく**PCアカウント（SYSTEM）**となります。
   そのため、共有フォルダーおよびNTFSのアクセス許可に **`Domain Computers`** を追加し、読み取り・実行（ログ出力先には変更・書き込み）の権限を付与してください。
