ヤマハの法人用無線LANアクセスポイント「WLX202」を2台使用し、WDS（Wireless Distribution System）機能によってLAN配線が困難なエリアへ無線通信範囲を拡張した設計・設定手順・注意点の完全ログです。

物理的な有線LAN敷設が難しい拠点やフロア間において、安定したL2ブリッジ環境を確立するための実践的な知識をまとめています。

---

## 1. ネットワーク構成とパラメーター設計

### 構成イメージ

親機（WDSアクセスポイント）を有線LANスイッチに接続し、子機（WDSステーション）を電源供給のみで配置して無線間でブリッジ通信を行います。どちらのAPにもスマホやPCといった無線クライアントが接続できるようにマルチSSID（VAP）構成を採用します。

```text
[ インターネット ]
        │
[ ルーター (192.168.100.1) ]
        │
[ 有線LANスイッチ ]
        │
        ├── [ PC (192.168.100.x) ]
        │
        ├── [ WLX202 - 親機 (WDS AP) ] ──── 192.168.100.241 (有線接続)
        │           │
        │           ┆ (無線 WDS Bridge / 5GHz W52 固定)
        │           │
        │     [ WLX202 - 子機 (WDS Station) ] ── 192.168.100.242 (電源供給のみ)
        │           │
        └───────────┴─ (無線クライアント接続 SSID: "Corp-Wi-Fi")
```

### 設計パラメーター一覧

| 項目 | 親機 (WDS AP) | 子機 (WDS Station) | 備考 |
| :--- | :--- | :--- | :--- |
| **機器型番** | YAMAHA WLX202 | YAMAHA WLX202 | - |
| **動作モード** | WDSアクセスポイント | WDSステーション | - |
| **IPアドレス** | `192.168.100.241/24` | `192.168.100.242/24` | 固定IP割り当て |
| **デフォルトGW** | `192.168.100.1` | `192.168.100.1` | - |
| **WDS使用帯域** | 5GHz (5GHz(1)) | 5GHz (5GHz(1)) | 干渉が少ない5GHzを使用 |
| **チャンネル** | W52 (36ch) 固定 | W52 (36ch) 固定 | DFS回避のためW52を指定 |
| **WDS通信用SSID** | `wds-link-backhaul` | `wds-link-backhaul` | WDS間専用の隠蔽SSID |
| **WDS暗号化方式** | WPA2-PSK (AES) | WPA2-PSK (AES) | パスフレーズは双方一致 |
| **対向MACアドレス** | 子機の5GHz MAC | 親機の5GHz MAC | 相互登録が必要 |
| **クライアント用SSID**| `Corp-Wi-Fi` | `Corp-Wi-Fi` | 同一SSIDでローミング可 |

## 2. 事前準備と構築前の注意点

設定作業に入る前に、以下の**3つのトラップ**に必ず注意してください。

:::message alert
**1. 工場出荷時IP（192.168.100.240）の重複**  
WLX202は初期IPアドレスが同一（`192.168.100.240`）です。2台を同時に同一ネットワークに接続するとIP重複障害が発生します。初期設定は必ず1台ずつ独立して行ってください。

**2. ループ障害（ブロードキャストストーム）**  
WDS設定完了後、子機（WDSステーション）のLANポートを有線スイッチに接続してしまうと、有線と無線の両方でL2ループが発生しネットワーク全体がダウンします。子機側は設定完了後に有線LANケーブルを抜き、PoEインジェクターまたはACアダプターによる電源供給のみの状態で運用してください。

**3. クラスター機能（仮想コントローラー）との折り合い**  
WLX202には自動で周囲のAPを検知してグループ化するクラスター機能がありますが、WDS構築時は「スタンドアローンモード」で個別にパラメータを設定・管理する手法が最も確実でトラブルを防げます。
:::

## 3. 詳細設定手順

### STEP 1: 個別IPアドレスの設定

まずはパソコンとWLX202を1対1（またはDHCPが動作していない閉じたスイッチ）で接続し、それぞれのIPアドレスを変更します。

#### 親機のIPアドレス設定

1. PCのIPアドレスを `192.168.100.10/24` 等に一時変更します。
2. ブラウザから `http://192.168.100.240/` にアクセスします。
3. ユーザー名 `admin` / パスワード空欄でログインします。
4. **[基本設定]** ＞ **[ネットワーク設定]** ＞ **[LANポート設定]** を開きます。
5. 以下の通り設定し、「設定」をクリックします。
   - **IPアドレス(IPv4)**: `192.168.100.241`
   - **ネットマスク**: `255.255.255.0` (`24`)
   - **デフォルトゲートウェイ**: `192.168.100.1`
6. 設定後、`http://192.168.100.241/` でアクセスし直せることを確認します。

#### 子機のIPアドレス設定

1. もう1台のWLX202を接続し、同様に `http://192.168.100.240/` にアクセスします。
2. **[基本設定]** ＞ **[ネットワーク設定]** ＞ **[LANポート設定]** を開きます。
3. IPアドレスを `192.168.100.242` に変更し設定を反映します。

---

### STEP 2: MACアドレスの事前確認

WDS接続のバインドおよび接続認証を行うため、互いの無線モジュール（5GHz）のMACアドレスを確認し手元にメモします。

1. 各APのWeb GUIにログインします。
2. **[ステータス]** ＞ **[インフォメーション]**（または本体背面のシール）を確認します。
3. **5GHz(1)のMACアドレス**をメモします。

```text
親機 5GHz MACアドレス: XX:XX:XX:AA:AA:AA
子機 5GHz MACアドレス: XX:XX:XX:BB:BB:BB
```

---

### STEP 3: 親機（WDSアクセスポイント）の設定

親機（192.168.100.241）の管理画面から無線設定とWDS用VAPを設定します。

#### 1. 無線基本設定（チャンネルの固定）

WDS接続を行う場合、チャンネルの自動変更機能（Auto Channel）は厳禁です。双方で同一の固定チャンネルを設定します。

1. **[無線設定]** ＞ **[基本無線設定]** を開きます。
2. **5GHz(1) 基本** の項目を次のように設定します。
   - **無線モジュール**: 有効
   - **モード**: IEEE 802.11a/n/ac
   - **チャンネル**: `36`（W52帯を指定）
   - **送信出力**: 100%
3. 「設定」をクリックします。

:::message
**なぜ 5GHz W52（36, 40, 44, 48ch）を選択するのか？**  
5GHz帯の W53/W56 チャンネルを使用すると、気象レーダーなどを検知した際に法令に基づきDFS（Dynamic Frequency Selection）が作動し、自動で60秒間の停波やチャンネル移動が発生します。WDS通信が切断されるリスクを避けるため、DFSの影響を受けない **W52** の固定利用が推奨されます。
:::

#### 2. WDS用VAP（VAP1）の設定

1. **[無線設定]** ＞ **[SSID 管理]** を開きます。
2. **VAP1** の「編集」または「追加」をクリックします。
3. 以下の項目を設定します。
   - **VAP機能**: 有効
   - **バインドする無線モジュール**: 5GHz(1)
   - **インターフェース動作モード**: `WDSアクセスポイント`
   - **SSID**: `wds-link-backhaul`
   - **対向WDSステーションのMACアドレス**: `XX:XX:XX:BB:BB:BB`（子機の5GHz MACアドレス）
   - **認証方式**: WPA2-PSK
   - **暗号化方式**: AES
   - **PSK (事前共有鍵)**: 超広範な32桁以上の英数字文字列を設定
4. 「設定」をクリックします。

#### 3. クライアント接続用VAP（VAP2）の設定

端末が接続するための無線エリアを設定します。

1. **[SSID 管理]** より **VAP2** を開きます。
2. 以下の項目を設定します。
   - **VAP機能**: 有効
   - **バインドする無線モジュール**: 5GHz(1) または 2.4GHz
   - **インターフェース動作モード**: `アクセスポイント`
   - **SSID**: `Corp-Wi-Fi`
   - **認証方式**: WPA2/WPA3-Personal
   - **PSK**: クライアント接続用パスフレーズ
3. 「設定」をクリックします。

---

### STEP 4: 子機（WDSステーション）の設定

子機（192.168.100.242）側の設定を行います。

#### 1. 無線基本設定

1. **[無線設定]** ＞ **[基本無線設定]** を開きます。
2. **5GHz(1) 基本** の項目を開きます。
   - **チャンネル**: `36`（親機と完全に一致させる）
3. 「設定」をクリックします。

#### 2. WDS用VAP（VAP1）の設定

1. **[無線設定]** ＞ **[SSID 管理]** を開き、**VAP1** の編集に入ります。
2. パラメータを設定します。
   - **VAP機能**: 有効
   - **バインドする無線モジュール**: 5GHz(1)
   - **インターフェース動作モード**: `WDSステーション`
   - **SSID**: `wds-link-backhaul`（親機と一致）
   - **接続先WDSアクセスポイントのMACアドレス**: `XX:XX:XX:AA:AA:AA`（親機の5GHz MACアドレス）
   - **認証方式**: WPA2-PSK
   - **暗号化方式**: AES
   - **PSK**: （親機で設定したものと同一の文字列）
3. 「設定」をクリックします。

#### 3. クライアント接続用VAP（VAP2）の設定

1. **VAP2** を編集します。
2. 親機と全く同じ設定を入力します。
   - **インターフェース動作モード**: `アクセスポイント`
   - **SSID**: `Corp-Wi-Fi`
   - **認証方式・PSK**: 親機と完全一致

これで子機側の設定は完了です。

## 4. 物理設置と疎通検証

設定が完了したら、現地に物理配置を行って疎通テストを実施します。

### 物理設置の手順

1. 親機（WLX202）を有線LANスイッチに接続し、電源を入れます。
2. 子機（WLX202）を通信拡張したい場所に設置し、**LANケーブルは接続せず**、電源のみを供給します（PoEインジェクターまたはACアダプター使用）。
3. 通電後、約2〜3分待機して両機器が完全に起動するのを待ちます。

### ステータス確認と検証手順

#### 1. WLX202 Web GUIによる接続状態の確認

親機の管理画面（`http://192.168.100.241/`）にログインします。

- **[ステータス]** ＞ **[無線端末情報]**（または **[WDSステータス]**）を開きます。
- 子機のMACアドレスが表示され、状態が「接続中（Connected）」になっていることを確認します。
- 受信感度（RSSI）を確認します。**-70dBm より良好な数値（例: -55dBm〜-65dBm）**に保たれていることが望ましいです。-80dBm以下の場合は設置場所を近づける必要があります。

#### 2. ICMP（Ping）による疎通確認

有線LANに接続されたPCから、子機の管理用IPアドレスへPingを実施します。

```bash
$ ping 192.168.100.242 -t

192.168.100.242 に ping を送信しています 32 バイトのデータ:
192.168.100.242 からの応答: バイト数 =32 時間 =2ms TTL=64
192.168.100.242 からの応答: バイト数 =32 時間 =3ms TTL=64
192.168.100.242 からの応答: バイト数 =32 時間 =2ms TTL=64
```

応答が安定して戻ってくれば、無事にWDS無線バックホールが確立されています。

#### 3. クライアントのローミングテスト

スマートフォンやラップトップを所持し、親機側から子機側へと移動しながら `Corp-Wi-Fi` への接続を維持したまま、スムーズにアクセスポイントが切替（ローミング）されるか検証します。

## 5. 現場でハマった注意点とトラブルシューティング

実際にWLX202でWDS環境を構築した際に直面したトラブルと、その解決策をナレッジとして残します。

### 1. 接続が極めて不安定 / 定期的に通信が切断される

* **原因**: 5GHz帯のチャンネル設定が「自動」または「W53 / W56」に設定されていた。
* **対処**: WDS通信は親機・子機が完全に同一チャンネルで同期している必要があります。「自動」にしていると周囲の干渉でチャンネルが移動した際にWDSリンクが切れます。また、DFSの発生するW53/W56ではなく、**必ず W52 (36, 40, 44, 48ch) のいずれかに固定**してください。

### 2. 子機に接続したクライアントがIPアドレスを取得できない（DHCPが届かない）

* **原因**: VAPの設定でVLAN IDの不一致、あるいはマルチキャスト/ブロードキャストの制限が影響している。
* **対処**: タグVLANを明示的に使用していない単純なL2ネットワークの場合、親機・子機の双方のVAP設定で「VLAN ID: 未指定（Untagged）」になっていることを確認してください。また、WDSのバックホールSSID（VAP1）でプライバシーセパレーターが「有効」になっていないか確認し、無効化してください。

### 3. 多段接続（数珠繋ぎ）を行おうとして通信不能になった

* **図解（非対応の構成）**:
  `[親機 (AP)] ~~~ (WDS) ~~~ [子機1 (ST)] ~~~ (WDS) ~~~ [子機2 (ST)]`
* **原因**: WLX202のWDS機能は仕様上、**1段目の子機まで（親機から見て直接接続される子機のみ）**しかサポートしていません。
* **対処**: 子機2を子機1に繋ぐ構成は不可能です。すべてのVilla（子機）は、親機を中心としたスター型配置（`親機 -> 子機1` および `親機 -> 子機2`）で直接親機とWDS接続するように配置してください。

```text
[ 正しい星型構成 ]
                ┌─── (WDS) ─── [ WLX202 子機 1 ]
                │
[ WLX202 親機 ] ┤
                │
                └─── (WDS) ─── [ WLX202 子機 2 ]
```

### 4. 機能制限に関する注意事項

WLX202を「WDSステーション」として動作させている場合、以下の機能制限が発生します。あらかじめ要件に含まれていないか確認しておきましょう。

- **L2MSスレーブ動作の制限**: ヤマハの管理プロトコル（L2MS）によるマップ自動表示において、WDSステーション配下の端末情報の表示が一部制限される場合があります。
- **プライバシーセパレーター**: WDSステーション設定時、一部のセキュリティセパレーター機能が併用不可となります。

## 6. 補足：現行機種の「メッシュWi-Fi」とWDSの比較

WLX202を活用する上でWDS機能は非常に有用ですが、**これから新規で機器を導入する場合は、現行機種が対応している「メッシュWi-Fi」の利用を強く推奨します。**

本記事のトラブルシューティングでも触れた通り、WLX202等のWDS機能には「1段目の子機（親機と直接通信する子機）までしか接続できない」という仕様があり、多段接続（数珠繋ぎ）による広域なエリア拡張ができません。これは将来的な拡張性の面で大きなボトルネックとなります。

一方、近年のアクセスポイントで主流となっているメッシュWi-Fi機能を利用すれば、以下のような大きなメリットがあります。

* **多段接続（マルチホップ）が可能**: 親機から離れた場所へも、子機同士を中継して柔軟にネットワークを広げられるため拡張性が圧倒的に高い。
* **自動最適化（セルフヒーリング）**: 障害発生時や電波状況の変化に応じて、アクセスポイント同士が最適な通信経路を自動で再構築してくれる。
* **設定・管理の簡略化**: WDSのように互いのMACアドレスを固定で打ち込んだり、チャンネルを手動で厳密に管理する手間が不要になる。

既存資産（WLX202など）を活かして1対1の無線ブリッジを構築する分にはWDSで十分事足りますが、将来的な拡張や日々の運用管理の手間を考慮すると、現在のトレンドではメッシュ対応機器（WLX222やWLX323など）の導入が圧倒的に有利です。用途と今後の拡張予定に合わせて構成をご検討ください。

## 7. まとめ

ヤマハ WLX202 を用いたWDS構築は、以下のポイントを押さえておくことで非常に堅牢で切れない無線延長環境を実現できます。

1. **チャンネルは 5GHz W52 (36〜48ch) に固定**（DFS回避の鉄則）
2. **IPアドレスは初期値から必ず分離し固定**
3. **バックホール用SSID（WDS専用）と端末接続用SSID（VAP）を明確に分けて設計**
4. **子機側を有線スイッチに繋がない**（L2ループ回避）

配線工事が難しい古民家リノベーションオフィスや、階を跨ぐスポット的なエリア拡張において、手持ちのWLX202のWDS機能は非常に有効なソリューションです。一方で、これからの新規導入や広い範囲のカバーを目指す場合はメッシュ対応機種を選ぶなど、要件に応じた機材選定の参考にしていただければ幸いです。
